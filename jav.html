JavaScript Predefined Objects Demonstration

1. Predefined String Functions

Function / Property Description Output Result
.length Returns the length of the string. -
.toUpperCase() Converts the string to upper case. -
.toLowerCase() Converts the string to lower case. -
.charAt(0) Returns the character at the specified index (0). -
.indexOf('Java') Returns the index of the first occurrence of specified text. -
.slice(7, 17) Extracts a section of a string and returns it as a new string. -

2. Predefined Math Functions

Method Description Output Result
Math.round(x) Rounds a number to the nearest integer. -
Math.ceil(x) Rounds a number up to the next largest integer. -
Math.floor(x) Rounds a number down to the next smallest integer. -
Math.sqrt(x) Returns the square root of a number. -
Math.abs(x) Returns the absolute (positive) value of a number. -
Math.random() Generates a random pseudo-number between 0 (inclusive) and 1 (exclusive). -
